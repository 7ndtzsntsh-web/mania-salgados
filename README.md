# Mania Salgados - Sabores Artesanais

Landing Page moderna, mobile-first e de alta conversão para a **Mania Salgados**, localizada em Florianópolis/SC (Bairro Coqueiros).

## Funcionalidades
- **Design Editorial Premium**: Paleta quente, tipografia com serifas modernas e acabamento artesanal refinado.
- **Links Dinâmicos de WhatsApp**: Botões de ação configurados com `encodeURIComponent`, número oficial e mensagens direcionadas.
- **Calculadora de Festas**: Ferramenta interativa para estimar centos de salgados por convidado e enviar o pedido diretamente para o WhatsApp.
- **Google Maps**: Iframe integrado apontando para o endereço oficial: *R. Prof. Bayer Filho, 305 - Coqueiros, Florianópolis - SC*.
- **Prova Social**: Seção de depoimentos e avaliação 5 estrelas do Google.
- **Pronto para Deploy**: Otimizado para deploy automático na Vercel.
